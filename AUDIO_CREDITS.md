# Audio credits / licenses

All game audio is **generated in code at runtime** (Web Audio API, `audio.js`). There are **no audio files,
no samples, and no recorded or copyrighted music** in this project.

| Sound | How it is made | License |
|---|---|---|
| Engines (dirt bike 2-stroke, Grom 4-stroke, Banshee twin 2-stroke, G35 V6) | oscillators at firing frequency from RPM, waveshaper distortion, filtered noise rasp, rev limiter stutter, shift dips | original, part of this repo |
| Tyre skid, wind, impacts, crash, splash, landings | filtered white noise + pitch-swept sine | original |
| City hum, sirens, Lake Merritt water + birds | brown/white noise filters, LFO siren, synthetic chirps | original |
| Block party beat at East Bay Dragons | original 16-step pattern (kick/snare/hat/bass) composed in code, no real songs | original |
| Crowd chatter, idling cruisers, taco truck sizzle + generator | band-passed noise, low sawtooth with amplitude wobble | original |

If CC0 recordings are ever added, list each file here with its source URL and "CC0 1.0".
